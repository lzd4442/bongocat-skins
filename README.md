# 🐱 BongoCat 皮肤集合

本仓库收集各种 BongoCat 猫咪打鼓桌面宠物的自定义皮肤。

## 📥 下载皮肤

每个皮肤都是一个 ZIP 文件，解压后放入 BongoCat 模型目录即可使用。

### 皮肤列表

| 皮肤名 | 说明 |
|--------|------|
| my-custom-skin | 自定义皮肤（基于用户提供的 PNG 模板） |

## 📦 使用方法

1. 下载喜欢的皮肤 ZIP 文件
2. 解压得到模型文件夹
3. 放入 BongoCat 应用的模型目录
4. 在 BongoCat 中选择该模型

## 🤝 贡献

欢迎提交 PR 添加新皮肤！
